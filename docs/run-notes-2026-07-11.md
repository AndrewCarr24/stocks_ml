# First real-data run notes (2026-07-11)

## Data coverage
- Membership: 854 tickers / 877 point-in-time stints reconstructed from Wikipedia.
- Prices: 652 tickers fetched; 202 delisted names unfetchable from yfinance
  (recorded in `data/manifest.json`) — the quantified survivorship residual.
- Corrupt-series filter dropped 9 tickers (repeated split-sized jumps in
  adjusted closes; CPWR confirmed corrupt). Known false positive: GME (its 2021
  squeeze had genuine back-to-back >90% days). Acceptable for a
  capital-preservation mandate; threshold in `prices.py` if revisited.
- EDGAR fundamentals: 498/498 current members, zero failures. Coverage ~0%
  pre-2010 rising to 96% (XBRL phase-in, as the spec predicted).
- Panel: ~452k rows, 2005-01-07 → present, median ~401 tickers/week.

## Champion selection (models/selection.md)
- **xgb champion: mean weekly rank IC 0.0126 over 611 walk-forward test weeks**,
  positive in 3/5 folds, ~7x the momentum baseline (0.0017).
- automl (0.0149 on its valid folds) was **excluded**: degenerate constant
  predictions in 2/5 folds (its internal RMSE grid search selected an
  ElasticNet that L1-shrank every coefficient to zero). The eligibility and
  final-fit-variation gates added in `champion.py` catch this class of failure.

## Backtest (reports/backtest.md), $100 from 2005, 5 bps one-way costs
- equal_topk: $12,170 (25.1% CAGR, Sharpe 0.76, deflated 0.97, max DD 66.7%).
- vol_scaled: $328 (5.7% CAGR, max DD 33.3%) — guard worked in GFC/2022,
  too slow for COVID's 4-week crash; conservative as tuned.
- kelly: $949 ≈ SPY's $959, similar Sharpe, similar DD.
- Holdout (last 2y, never used in selection): equal_topk +48.6% vs SPY +40.7%.

## Cautions before trusting equal_topk's 25% CAGR with real money
- Frictionless fills at next-day opens; real spreads (especially in crises)
  and the fixed 5 bps assumption flatter the result.
- Residual survivorship bias: 202 delisted names absent from the panel.
- One full walk-forward history = one sample; the live paper ledger exists to
  build out-of-sample evidence before sizing beyond $100.

## Two invalidated runs (why reruns happened)
1. Run 1: CPWR-style corrupted delisted-ticker data produced equal_topk
   "43% CAGR / +196% GFC" — implausibility gate tripped; corrupt-series
   detector added; numbers void.
2. Run 2: automl champion predicted a constant → near-alphabetical picks;
   selection-eligibility gates added; numbers void.
